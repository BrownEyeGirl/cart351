# Welcome to my CART 351 Repo! 
## Feedback Project 1

***Journal***, **By: Nat**

The Journal logs entries and saves past entries, telling the user the activity of writing not the journal entry itself. It logs how long someone wrote for, logs key strokes, nouns, emotional words, and an overall analysis 
of the journal entry. After submitting, the program takes information from user and displays it. I think this is a very creative use of APIs; using Spacy API to detect word tone 
and NLP Analysis. It would be awesome if it went public, gathered statistics about everyone and publishing them. It is also a useful tool to have in the backend of a journalling 
program in therapy, allowing more insight into the writers mind than a standard journal entry. 

***Clouds*** **By: Ben** 
Link: https://github.com/benmsky/CART-351-REPO-main/tree/main/CART-351-REPO-main/MINI-PROJECTS/benjamin-macknofsky_mini_project_one

The Cloud website stood out to me because of its originality and nostalgic interface. The clouds being generated by P5.js is a wonderful idea and a great
use of the P5.js skills from last year. The side collects user input on what the cloud looks like and displays it around the clouds. The site was 
easy to interact with and the concept was original and well executed. Modelled after Windows XP (based on youtube tutorial), the dynamic interface with 
soft movements were well executed and the *whisper* effect was clear to interpret. The overall vibe of the site was nostalgically familiar while still
having original aspects. I also appreciate how the algorithm took into account different input and removed "the" or plurals to make sure words weren't repeated.
I asked for the code for this project because it was so fascinating to me. To push this further, I'd love to see this published and change shapes daily,
I think there is also opportunity for nostalgic sound effects to be added to the interface, or an ambient background composition to make the experience 
more meditative. 

***Terminal de Jack*** **By: Jack**
The sleek hacker-themed terminal allows you to create an admin, gives commands to communicate with terminal. The user adds class notes, new user, and lists notes, 
and then allows you to pull them up after creating them. Though this is class notes themed, I would be cool to have little games to play during “class” 
for engagement, or something similar to the old ASCII StarWars animations that Macs used to have. It would be cool if you connected to the internet somehow 
so you could search simple questions, or connect to a dictionary API to get definitions of words during “class”.
